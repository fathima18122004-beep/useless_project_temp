# 1. Project Overview

## Project Name : **USELESS BANK™ ATM**

## Project Concept

Traditional ATMs and banking systems are designed to provide useful financial services such as withdrawals, deposits, transfers and payments.

USELESS BANK™ ATM takes the opposite approach.

It is a deliberately unnecessary banking system that performs a complete transaction while creating absolutely no financial value.

The project combines embedded electronics, mechanical design, software development and user interaction into a single functional prototype.

## Core Principle

> **Maximum processing. Minimum purpose.**

---

# 2. Project Description

USELESS BANK™ ATM is an automated banking terminal that processes a ₹1 transaction from beginning to end.

The user interacts with the physical ATM, while an Arduino UNO controls the hardware mechanism and communicates with a React web application through USB serial communication.

During a transaction:

- The system activates the LED.
- The buzzer provides transaction feedback.
- The servo motor operates the physical mechanism.
- The React application displays the transaction progress.
- The system completes the transaction.
- The original ₹1 is returned to the user.

# 8. Transaction Processing

When the transaction starts:
