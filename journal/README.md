# Useless Bank ATM — Final Project Journal

This version is built around the actual project photo and uploaded build video.

## Folder
- `index.html` — website
- `style.css` — styling
- `script.js` — animations and digital ATM
- `images/final-atm.jpg` — uploaded project photo
- `videos/build-diary.mp4` — uploaded project video

## Run locally
Open `index.html` in a browser, or use the VS Code Live Server extension.

## Customize
Replace the prepared placeholder problem descriptions with your real testing results. Add more photos to `images/` and additional video files to `videos/` if needed.

## Publish
Upload the complete folder to a GitHub repository and enable GitHub Pages from Settings → Pages.
