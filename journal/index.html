01

THE IDEA

What if we built a bank that did absolutely nothing?

Most projects try to solve a real problem. We decided to do something different.

Our goal was simple: build a functioning ATM that completes an entire banking transaction, while making absolutely no financial difference.

“ Maximum processing. Minimum purpose. ”
02

BEFORE THE CODE

First, there was cardboard.

Before React, Arduino and serial communication, we had cardboard, glue, tape, measurements and one very important question:

“Will the ₹1 token actually move through this thing?”

We designed and built the physical ATM enclosure by hand. We measured the structure, cut cardboard, joined the pieces with glue and tape, and created a mechanism through which the token could enter, move through the machine and come back out.

SOFTWARE

The useless bank needed serious software.

The front end was built using React and JavaScript. We created a banking-style interface that displays transaction information, processing status, hardware connection and transaction history.

WHAT WE LEARNED

A useless project taught us useful things.

01

Hardware matters.

A software idea becomes very different when a physical object has to actually move.

02

Small measurements matter.

The physical mechanism depends on accurate cutting, positioning and alignment.

03

Communication is a system.

Connecting a browser to an Arduino required understanding the complete data flow.

04

Projects are iterative.

Building something from scratch means testing, changing and testing again.
